# Envia Privacy Policy

**Last updated: October 2026**

Envia is a Windows application that lets you create and apply personalized PC environments. This policy describes the currently identified network functionality and the intended local handling of settings.

## Internet Access

Envia connects to the internet to retrieve the developer's GitHub profile picture for display in the About section. The request is made to GitHub or the image-hosting infrastructure used to serve that profile picture. The relevant service may receive ordinary request information, such as your IP address, as part of serving the request; its handling of that information is governed by the service provider's own policies.

## Environment Profiles and Settings

Envia allows you to configure environments and application preferences, including supported Windows settings and startup or tray behavior. These settings are intended to be stored locally on your Windows computer. This policy does not claim a specific file path because the storage location should be confirmed against the implementation for the release being distributed.

## Analytics, Advertising, and Telemetry

No analytics, advertising, or telemetry feature has been identified from the information supplied for this policy. This statement should be rechecked against the source code and packaged dependencies before release, and updated if the application or a component collects diagnostic, usage, or other information.

## Third-Party Services

The GitHub profile-picture request is subject to GitHub's terms and privacy practices. Envia does not control how GitHub processes requests received by its services.

## Your Choices

If you do not want Envia to retrieve the profile picture, you can block Envia's network access through Windows or a network security tool. The picture may then fail to load. Other functionality may continue to work, depending on the application version and configuration.

## Children's Privacy

Envia is a general-purpose Windows utility and is not specifically directed at children.

## Changes to This Policy

This policy may be updated if Envia's functionality or data practices change. The current version should be published with the relevant release or on the official project page.
